# Radical Minimalism & Simple UX Design Skill

This skill enforces strict minimalism, calm elegance, and maximum clarity across all digital interfaces in GUAKI and related applications.

---

## 🎯 Core Principles

1. **One Primary Action Per View:**
   - Every screen must guide the user to **one** clear, obvious primary action (e.g. searching, contacting by WhatsApp, viewing a profile).
   - Secondary actions must exist quietly in the background without competing for visual attention.

2. **Aggressive Noise Reduction (0% Clutter):**
   - If an element, badge, counter, icon, or text block does not directly help the user make an immediate decision, **remove it**.
   - No decorative bloat, no random emoji overload, no unnecessary cards inside cards.

3. **Generous Whitespace & Breathing Room:**
   - Use expansive padding and margins (`24px` to `64px`) to let typography and imagery breathe.
   - The interface should feel calm, orderly, and serene—never cramped or dense.

4. **Editorial Typography Hierarchy:**
   - Large, crisp, human headlines.
   - Comfortable, readable body text with relaxed line-height (`1.55`–`1.65`).
   - Muted, quiet secondary labels (`#607067` / `#87958D`).

5. **Soft Tactile Surfaces (Not Heavy):**
   - Subtle, soft glass surfaces with matte blur and light diffuse highlights.
   - Micro-interactions only (150ms–220ms ease-out).
   - Zero aggressive bounce, zero glowing borders, zero infinite animations.

6. **Mobile Ergonomics:**
   - Minimum 44px touch targets.
   - Full-width clean cards on mobile.
   - Search always reachable with one thumb.

---

## 🛠️ Verification Checklist

- [ ] Is there only ONE prominent button/action on the screen?
- [ ] Is all text necessary and clear, free of filler jargon?
- [ ] Are the margins and padding generous and uncluttered?
- [ ] Are shadows soft and barely perceptible rather than heavy or dark?
- [ ] Does the page load fast with zero visual jitter or layout shift?
