# 🥑 Guaki Platform — Plataforma SaaS & Ecosistema de Agentes

> [!NOTE]
> **Guaki Platform** es la suite de aplicaciones y servicios SaaS que aloja los agentes autónomos de negocio, gestión de proyectos y base de datos unificada sobre Supabase PostgreSQL.

---

## 🏗️ Módulos Principales
- **Agentes Cognitivos:** Catálogo de asistentes de ventas, finanzas, operaciones y soporte.
- **Data Engine:** Base de datos con Row Level Security (RLS) multi-tenant y soporte de embeddings vectoriales (pgvector).
- **Glass UI Dashboard:** Interfaz moderna y reactiva construida en Next.js y TailwindCSS.
